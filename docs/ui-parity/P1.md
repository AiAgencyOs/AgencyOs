## Owner questions
- Sprint (task page, Related -> Sprint): the specs define no sprint model (cadence, capacity, whether a sprint spans projects). What is a sprint here, and does it belong to a project or to the agency?
- Project team "Department" and "Online" (image 15): no department is stored on a member and there is no presence signal. Should a member carry a department (a fixed list you set), and is "Online" wanted at all given the app deliberately shows last active instead?
- The reference's "Discussion" tab: project conversation lives in Communication; should that tab carry the name Discussion?
- Project type, technology, tags on the project header (images 17, 30, 44): no such fields. Which of these do you want recorded, and as fixed lists or free text?

## Still different (data or by design)
- Status delta chips show only where a past period exists; a project with no history shows no chip rather than a made-up one.
- Second KPI row on My tasks (due today, blocked, waiting, no due date) is beyond the reference (SCR-021 asks for it).
- Milestone "Dependencies" list and "Related files" per milestone: dependencies between payment milestones are not stored, and files are filed per project, so the rail shows the project's file count.
- Board Calendar and Tasks Calendar view are links to the project calendar tab, not an inline calendar.
