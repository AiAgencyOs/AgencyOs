## Owner questions
1. Does a requirement carry a Priority and an Assignee? Scope items have neither, and a frozen scope cannot be edited, so adding them means a business decision on who sets them and when.
2. Do requirements carry file attachments? Files attach to the project (Files tab), not to an item.
3. Should "New Folder" exist as an action? A folder is only a path on a file today, so an empty folder cannot exist; and should the Files tab get a Grid/List toggle?
4. Should the project Communication tab classify conversations as Client / Team / Internal? The data only distinguishes client-facing threads from the agency's own group.

## Round 3 (stream R1) — the owner's answers to questions 1-4 above

1. Priority and Assignee on a requirement: built (owner decision 5). 2. Attachments: built as links to existing project files (decision 6). 3. New Folder and Grid/List: built (decision 7). 4. Thread classification: Client / Internal only, no Team (decision 8); the tab is named Discussion (decision 3). Details in R1.md.
