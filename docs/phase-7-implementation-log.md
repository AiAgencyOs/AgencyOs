## Decisions worth knowing
- **The door flag.** Every Phase 7 table refuses a write unless a door set the transaction-local flag `projects.p7_door`. It stops a raw service-role write. A single test transaction keeps the flag on after the first door, so the verifier switches it off before each raw-write test.
- **Two layers, red-proved together.** "Only an approved package is delivered" is held by the door and by the transition map in the package trigger; "validated needs no open incident" by the pause flag and by the incident check. Removing one leaves the other holding, so each pair is red-proved by removing both.
- **A person validates, never the runner.** The validation doors are granted to `authenticated` only; a service-role caller is denied. The deployment executor, a service-role runner, cannot validate its own deployment.
- **Completion gate scope and acceptance exceptions** are the only two exceptionable gates, bound to the exact delivered package and commit.
