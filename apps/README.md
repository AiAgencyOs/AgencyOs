# apps - Frontend Applications

This folder contains the scaffold for frontend applications and client-facing code.

Structure:
- admin-dashboard/: Admin console and internal tools
- owner-dashboard/: Agency owner / management interface
- client-portal/: Client-facing portal and project tracking
- mobile/: Mobile applications (Flutter)

Each subfolder contains a README.md describing purpose and recommended tech choices (Next.js for web, Flutter for mobile). Do not add application code here until the architecture is finalized.
