# services - Backend Services

This folder holds microservice templates and domain services. Each service should be a standalone repository or a local package depending on delivery choice.

Services:
- sales-service: Leads, quotes, invoices
- project-service: Projects, tasks, timelines
- approval-service: Approval workflows and audit trails
- ai-orchestrator: AI orchestration, prompts, and pipelines

Each service folder contains a README.md describing domain responsibilities and integration points.
